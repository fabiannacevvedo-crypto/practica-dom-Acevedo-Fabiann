# Práctica — Manipulación del DOM con JavaScript

## Objetivo
Desarrollar una galería de superhéroes aplicando manipulación del DOM con JavaScript.

## Funcionalidades
- Renderizado dinámico de cards con Bootstrap.
- Filtro por nombre.
- Formulario para agregar nuevos personajes.
- Botón para eliminar personajes.
- Estilos personalizados con CSS.

## Tecnologías
HTML · CSS · Bootstrap · JavaScript
